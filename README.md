# Hybrid-ML-Framework-for-Cryptocurrency-Price-Prediction
This project proposes a hybrid deep learning model for price movement prediction of 
cryptocurrencies using a combination of Convolutional Neural Networks (CNN), Long 
Short-Term Memory (LSTM) networks and BiLSTM networks. The system is developed to be 
able to deal with the extremely volatile and nonlinear characteristics of cryptocurrency markets 
by learning both short term data and long-term dependencies in financial time series data. This 
will help enrich the prediction framework provided by the model further with an appreciation of 
local trends, relationships over time and global contextual patterns in the data.  
It provides training on seven popular cryptocurrencies: Bitcoin, Ethereum, Binance Coin, XRP, 
Cardano, Solana and Dogecoin with historical OHLCV data and sentiment data from the Fear 
and Greed Index. To gain knowledge about the market behavior, a detailed feature engineering 
method is used from the raw data to obtain significant indicators and this enables the model to 
learn. The system demonstrates good predictability, especially in the context of Bitcoin, with 
directional predictability > 70% achieved with high confidence, pointing to the potential feasibility 
of the hybrid strategy. Besides the development of the model, it is a full stack project where the 
backend is built from scratch using FastAPi and the frontend is developed using the React 
framework, where the users can use the actual model predictions, analyse the model outputs in 
a user friendly and intuitive way and can visualize trends through the interactive charts.
